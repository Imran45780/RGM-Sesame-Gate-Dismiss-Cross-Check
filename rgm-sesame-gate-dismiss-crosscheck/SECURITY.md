# Security Policy

## Scope

This repository contains a browser userscript that interacts with a configured internal web console.

## Reporting a concern

Do not report security issues by publishing confidential operational details in a public issue. Use the organization's approved internal security or reporting channel for sensitive findings.

For non-sensitive code concerns, open a repository issue after confirming that doing so is permitted by your organization's policies.

## Safe-use notes

- Review the script before installing it.
- Install it only in authorized environments.
- Do not add credentials, tokens, or external data collection.
- This client-side script is not a substitute for backend controls or operational procedures.
